# 🎮 Simon Game

A fun and interactive memory-based game built using **HTML, CSS, and JavaScript**.  
The classic Simon Game challenges players to remember and repeat an ever-increasing sequence of colors and sounds.

---

## ✨ Features
- 🎨 Colorful and responsive design  
- 🔊 Sound feedback for each button press  
- 📈 Increasing difficulty as you progress  
- ⚡ Lightweight and browser-based  

---

## 🚀 Live Demo
[Play the Game Here](https://AbhishekThite387.github.io/simongame/)  

---

## 🛠️ Tech Stack
- **HTML5** – Structure  
- **CSS3** – Styling & Animations  
- **JavaScript (ES6)** – Game Logic  

---

## 📂 How to Run Locally
1. Clone this repository:
   ```bash
   git clone https://github.com/AbhishekThite387/simongame.git
   ```
2. Open the project folder:
   ```bash
   cd simongame
   ```
3. Open `index.html` in your browser. 🎉
